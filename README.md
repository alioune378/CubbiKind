# CubbiKind Twins

Waitlist site and Twin Hug demo for CubbiKind Twins: one bear, two homes, one family.

- `index.html`: waitlist page with $5 refundable reservation (Netlify Forms)
- `demo.html`: clickable Twin Hug demo

Set the Stripe Payment Link in `RESERVE_URL` at the bottom of `index.html`.

Designed & Developed by Dalal Technologies.

Live: https://cubbikinddemo.netlify.app
